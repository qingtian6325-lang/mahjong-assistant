# 麻将实景识牌军师：全局四家实时盯盘与攻防决策系统设计文档 (Scheme A)

- **日期**：2026-11-07
- **项目**：`mahjong-assistant`（独立仓库 `c:\Users\hp\Documents\antigravity\mahjong-assistant`）
- **目标场景**：手机直接对准真实麻将桌拍摄，实时监控四家（自家、下家、对家、上家）的手牌、出牌（牌河）与吃/碰/杠副露，并在别人出牌和自家出牌两个阶段实时给出吃碰胡拦截建议与全局攻防出牌建议。

---

## 1. 核心意图与背景 (Intent & Why)
此前版本的 `mahjong-assistant` 仅支持手动点击拍照识别自家手牌（13/14 张），不包含其余三家的舍牌、吃碰杠副露信息，也无法在画面变化时自动连续触发。
真实牌局中，“该打哪张”和“别人打的牌该不该吃/碰/杠/胡”高度依赖**全桌已现张数（算绝张）**以及**三家（上/对/下家）已经吃了什么、碰了什么、打了什么（算安全熟张与对手做牌方向）**。因此需要将系统升级为**四家全局实时盯盘军师**。

---

## 2. 目标与非目标 (Goals, Non-Goals, Anti-Goals)

### Goals (目标)
1. **智能帧稳定实时盯盘（Auto-Watch）**：开启摄像头后无需每次手动按快门；通过画面动态差分检测（Motion & Stability Detection），当摸牌/打牌的手移开、画面稳定约 0.6 秒且与上一稳定帧相比有变化时，自动触发全局识别并刷新建议。
2. **四家全局状态追踪（谁打了什么、谁吃了什么、谁碰/杠了什么）**：
   - 完整维护四家（`bottom` 自家、`right` 下家、`top` 对家、`left` 上家）的副露列表（吃、碰、杠）与舍牌列表（牌河），以及场上的「最新动作（谁刚打了哪张牌）」。
   - 支持 Gemini Vision 全局五区结构化 JSON 识牌 + 本地五区色彩/纹理块特征识别双引擎。
3. **沙盘点选与语音直报双保险**：
   - 针对真实牌桌远端（如对家）可能出现的反光或手部遮挡，提供四家可视化战局沙盘与「方位动作速记切换栏」（一键记录“上家刚打 / 对家碰 / 下家吃”等）以及浏览器实时语音口令识别（如说“上家打三万”、“对家碰红中”）。
4. **全场景实时军师建议 + 语音播报**：
   - **对手出牌瞬间（拦截决策）**：当上家/对家/下家打出一张牌时，立即计算并提示是否应该**胡、杠、碰、吃（含具体用哪两张吃）或过**，以及吃/碰之后应该打出哪张牌。
   - **自家出牌阶段（攻防决策）**：精准扣减全桌四家已见牌数（34 种牌剩余张数与绝张预警），结合三家吃碰牌路推演每张牌的**点炮危险度（现物安全牌 vs 生张高危牌）**，给出 Top 3 攻防出牌推荐。
   - **实时 TTS 语音报招（可选开关）**：识别到新局面后自动语音简报核心建议（如“上家打三万，建议用四五万吃，打北风”或“建议打九万”）。

### Non-Goals (非目标)
- 不修改原联机打牌仓库 `elegant-babbage` 的代码，所有改动严格在独立项目 `mahjong-assistant` 中进行。
- 不依赖任何需要后端服务器部署的付费第三方服务（纯前端静态部署于 GitHub Pages，本地算力 + 可选用户自填 Gemini API Key）。

### Anti-Goals (反目标/绝对避免)
- **严禁在有人手挡住镜头晃动时乱跳识别结果**：必须经过帧间静止稳定检测（Debounce）才触发更新，且支持增量防抖合并，避免单帧局部遮挡清空已记录的三家牌河。
- **严禁把界面做成复杂难点的多层弹窗**：所有实时取景、四家全局沙盘、吃碰拦截提示和 Top 3 出牌建议必须在一个直观的响应式单页中一目了然。

## 3. 现实约束 (Constraints)
- 真实麻将桌视角下，自家手牌在画面下方（立放或微仰），三家吃碰与中央牌河在画面中上方（平铺），因此取景框需提供**五区战术网格引导**（上家左、对家上、下家右、牌河中、自家下），同时允许用户切换「全桌五区盯盘」或「近拍自家手牌 + 沙盘/语音记三家」。
- 移动端屏幕宽度有限，四家沙盘需采用紧凑十字/方位布局，并在牌库上直接显示全桌剩余张数角标。

---

## 4. 方案选择 (Approaches)
- **方案 A（已选定）**：全桌五区自动盯盘 + 四家实战沙盘与语音/点选双保险。兼顾全自动摄像头盯盘与真实牌桌复杂视角下的 100% 容错修正能力。
- **方案 B（放弃）**：纯视觉定时全覆盖模式，无交互沙盘。在真实牌桌上遇到手部遮挡或反光时会导致全局牌河跳变且无法纠正。
- **方案 C（放弃）**：仅拍手牌、完全靠手动记三家。缺少全桌自动视觉感知能力。

## 5. 核心架构与详细设计 (Detailed Architecture)

### 5.1 全局牌局状态模型 (`tableState` in `camera-assist.js`)
```js
var tableState = {
  myHand: [...], // 自家当前手牌 (13/14 或吃碰后 10/11, 7/8, 4/5, 1/2)
  seats: {
    bottom: { name: '自家(我)', melds: [], discards: [] },
    right:  { name: '下家(右)', melds: [], discards: [] },
    top:    { name: '对家(上)', melds: [], discards: [] },
    left:   { name: '上家(左)', melds: [], discards: [] }
  },
  latestEvent: null, // { seat: 'left'|'top'|'right'|'bottom', type: 'discard'|'chi'|'peng'|'gang', tile: 2, tiles: [...] }
  actionLog: []      // 按时间倒序排列的全局出牌/吃碰流水记录
};
```
- **全桌已见牌统计 (`computeVisibleCounts(tableState)`)**：遍历 `seats` 四家的所有 `discards` 与 `melds`（加上 `myHand`），精确计算 0..34 每种麻将牌在全桌已出现的张数與剩余张数 `remaining = Math.max(0, 4 - visible)`。

### 5.2 智能帧稳定自动盯盘 (`Auto-Watch Monitor` in `camera-assist.js`)
- 新增 **「🔴 实时盯盘中 / ▶️ 开启实时盯盘」** 主控开关与灵敏度/间隔控制（默认：智能动态感应 + 2.5秒防漏检巡检）。
- **帧间运动与静止检测器 (`checkFrameStability`)**：
  - 使用一个隐藏的 `64x36` 微型 Canvas 每 `250ms` 采样当前视频流灰度像素。
  - 计算当前帧与上一采样帧的平均像素差 `motionDiff`，以及当前帧与“上一次已识别基准帧”的差异 `sceneDiff`。
  - 当检测到 `sceneDiff > 阈值`（画面相比上次识别发生了实质变化，如摸牌、出牌、吃碰）且连续 2~3 次采样 `motionDiff < 静止阈值`（手已经离开画面、画面稳定约 0.6 秒）时，自动调用 `captureAndRecognize(video, false, true)`。
  - 在取景框顶部实时显示状态呼吸灯：`🟢 画面稳定·实时盯盘中` -> `🟡 检测到摸打动作·等待手移开...` -> `⚡ 正在抓拍解析全局牌面...`。

### 5.3 全局多区域识别（Gemini Vision + 本地五区 CV）
- **Gemini Vision 全局五区识别 (`recognizeFullTableWithGemini`)**：
  - Prompt 升级为识别全桌五个区域：自家手牌 (`myHand`)、四家各自的吃/碰/杠副露 (`seats[seat].melds`)、四家已打出的牌 (`seats[seat].discards`) 以及场面上最新打出的一张牌 (`latestDiscard`)。
  - **智能增量合并 (`applyRecognizedTableSnapshot`)**：将识别出的手牌和四家副露/舍牌与当前 `tableState` 比对，如果发现某一家新增了舍牌（例如上家多了一张 `三万`），自动生成 `latestEvent = { seat: 'left', type: 'discard', tile: 2 }` 并触发拦截分析与语音提醒。
- **本地五区特征引擎 (`recognizeFullTableLocally`)**：
  - 支持「全桌五区模式」与「手牌特写模式」：对取景框底部手牌区做精确切片识牌；在全桌模式下同时扫描左/上/右/中区域的麻将牌块，识别新增出牌。

### 5.4 四家全局可视沙盘与极速交互 (`index.html` & `camera-assist.js`)
- **四家战局沙盘（4-Seat Tactical Board）**：
  - 展示 **上家(左)、对家(上)、下家(右)、自家(下)** 四个方位卡片：
    - 显示各家**副露区**（吃/碰/杠微缩 3D 牌组，支持点击 `×` 撤销误录）與**舍牌河**（显示已打出的牌，最新打出的一张带高亮脉冲边框）。
    - 显示各家 **AI 牌路威胁标签**（由 `engine.js` 实时分析：如 `⚠️ 2副露·筒子混一色倾向`、`🛡️ 现物熟张：一万、东风`）。
- **「谁做了什么」极速录入模式切换栏 + 语音直报**：
  - 牌库上方提供一键动作模式栏：
    - `🀄 改/摸自家手牌`（默认）
    - `⬅️ 上家打牌` | `⬅️ 上家吃/碰`
    - `⬆️ 对家打牌` | `⬆️ 对家吃/碰`
    - `➡️ 下家打牌` | `➡️ 下家吃/碰`
    - `⬇️ 自家吃/碰/杠`
  - 比如在牌桌上看到对家打了一张「五筒」或碰了「红中」，哪怕手机没拍到远端，只需点一下 `⬆️ 对家打牌` 再点 `五筒`（或开启 `🎙️ 语音盯盘` 直接说“对家打五筒”），0.1 秒即刻入盘并算出是否该碰/胡！

### 5.5 雀神 AI 全局攻防与吃碰拦截引擎 (`engine.js`)
- 新增 `analyzeFullTable(tableState)`（兼容并增强原 `analyzeAssistantHand`）：
  1. **对手出牌拦截建议 (`claimAdvice`)**：
     - 当 `latestEvent` 为其他三家（上/对/下家）刚打出一张牌 `T`，且自家手牌为 13/10/7/4/1 张（等摸/可鸣牌状态）时：
     - 自动评估 **胡（点炮胡）**、**明杠**、**碰**、**吃（仅限上家出牌时，遍历所有合法顺子吃法）** 与 **过（不鸣牌）** 的期望收益对比。
     - 输出清晰的拦截决策卡：
       - 推荐动作（如 `🔥 强烈建议【碰】！` 或 `✅ 建议用【二万+四万】吃【三万】` 或 `✋ 建议【过】（不吃不碰）`）
       - 鸣牌后的最佳衔接出牌（如 `吃完后建议打出【北风】，向听数前进且听口达 9 张`）
       - 一键执行按钮 `⚡ 执行吃/碰并打出推荐牌`，点击即自动扣除手牌、加入自家副露并更新牌局。
  2. **三家牌路推演与点炮风险评估 (`opponentThreats` & `tileDangerMap`)**：
     - 分析三家的副露数、副露花色集中度、以及舍牌中缺门情况：
       - 若某家副露 ≥ 2 且集中在同一花色（或全为字牌/刻子），标记该花色生张为高危；
       - 若某张牌已被某家打过（现物），对该家安全度为 100%；若全桌已见 3~4 张（绝张/壁牌），对顺子吃胡威胁大幅降低。
     - 在自家 Top 3 出牌推荐中，为每张推荐牌附带 **攻防双维度指标**：`有效进张/听牌数（已扣除四家已见牌）` + `🛡️ 安全度/点炮风险标签`。
